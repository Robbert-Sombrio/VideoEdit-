# VideoEdit

The /video-edit skill (from tenfoldmarc/video-edit-skill) set up for The Fluent Edge.

- **Cloud sessions:** start a Claude Code session with this repo selected and type `/video-edit`. Attach your clips in the chat.
- **On a Mac:** `git clone https://github.com/Robbert-Sombrio/VideoEdit- ~/VideoEdit && cp -r ~/VideoEdit/.claude/skills/video-edit ~/.claude/skills/`

The skill itself lives in `.claude/skills/video-edit/`.
